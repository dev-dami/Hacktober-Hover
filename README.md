# Hacktober-Hover
A Bun monorepo for NAFDAC Verify.

- `apps/nafdac-verify`: Next.js application
- `packages/`: shared packages as the project grows
- `data/` and `scripts/`: repository-wide data and utilities

Run `bun install` from the repository root, then `bun dev` to start the app.
Use `bun run build` and `bun run lint` to check it.
